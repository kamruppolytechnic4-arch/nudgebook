How a WhatsApp link works

A WhatsApp link looks like https://wa.me/14155550134?text=Hello. When someone taps it, WhatsApp opens a chat with that number and the message ready to send. It works on phones and on WhatsApp Web.

Rules for the number

  • Start with the country code (1 for USA/Canada, 44 for UK, 91 for India, 234 for Nigeria).
  • No + sign, spaces, brackets or dashes.
  • Drop the leading 0 of a local number. UK 07700 900123 becomes 447700900123.

Where to use it

  • Instagram, TikTok or Facebook bio: “Message us on WhatsApp”.
  • A “Chat with us” button on your website.
  • Printed on a flyer or menu as a QR code.
  • In a follow-up email so customers reply in one tap.
